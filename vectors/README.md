# Shared test vectors

Frozen golden data consumed by all implementations: the TypeScript tests under
`packages/spark/tests/` and `packages/spark-wasm/tests/`, the Rust unit tests in
`crates/spark-crypto`, the C ABI host tests, and the upstream differential suite
in `crates/interop` read exactly these files. Do not reformat, re-wrap, or
normalize them; any change is a deliberate contract change and must land in
every implementation in the same commit.

**Every vector file begins with a header noting its upstream source and commit
and the words "test only, never for funds".** Secrets and private keys in these
files are fixed fixtures, not credentials; nothing in this directory may ever
be used to secure real funds.

Line files (`.txt`, `.hex`) are data-only: UTF-8, LF line endings, a trailing
newline, and no `#` header comments — provenance lives in this README and in the
`source` envelope of JSON files instead. Runners must not need comment skipping.

## Registration

Every file here (except this README) must be referenced by a capability in
`parity.json`; `bun run lint` fails on unregistered vectors.

## Provenance

| File                 | Contents                                                                      | Generated by                                                     |
| -------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `frost-commit.json`  | `hedge`, `random` → `nonces`, `commitments`                                   | `spark-crypto` itself (frozen)                                   |
| `frost-sign.json`    | fixed keys, nonces, commitments, message, optional adaptor → user share + aggregate signature | upstream `spark-frost` via `crates/interop` |
| `ecies.json`         | secret key, public key, plaintext, `random` → ciphertext; upstream-decryptable | `crates/interop`                                                 |
| `vss.json`           | secret, threshold, count, `random` → proofs + shares; upstream-validated       | `crates/interop`                                                 |

Regenerate with `SPARK_WRITE_VECTORS=1 cargo test -p qntx-spark-interop --test vectors`
inside `crates/interop` (needs `protoc` for the upstream crate's build).
`spark-crypto/tests/vectors.rs` replays the same files without upstream
dependencies, and `crates/interop` re-verifies them against upstream.
